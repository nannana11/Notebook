# 📖 Notebook (笔记本)

一个基于 Java Swing 纯手工打造、界面清爽、即开即用的多用户轻量级桌面随手记应用。💡

本项目现已全面开源，此版本经过完整硬核封装，内置独立轻量级运行环境，Windows 用户无需配置任何 Java 环境变量，解压即可直接双击运行！

---

## 📬 适用场景 ✨
- 📖 **课堂记录**：快速记录课堂要点与核心大纲。
- 📊 **每日记账**：随手记录日常开销与账目流水。
- ⏰ **日程安排**：有条不紊地规划个人备忘录与待办清单。
- ✍️ **好词佳句**：随时摘抄灵感火花与精美段落。

---

## 🛠️ v1.2 核心功能特性

- 🚀 **绿色解压即用**：压缩包内自带轻量级 JRE 运行时，双击即可无痛在 Windows 平台上完美呼出。
- 🔐 **多用户账号隔离**：支持多账号注册与密码登录，不同账号数据完全隔离，极具隐私性。
- 💾 **本地安全持久化**：数据采用本地序列化保存（`userData.dat`），离线可用，完全不用担心隐私泄露。
- 🔄 **工业级自动保存**：彻底告别丢失风险！在左侧列表**切换笔记**或**直接关闭程序**时，系统会自动将内容锁定并安全存盘。
- ⚡ **全局上下文检索**：检索能力全面升级！支持**大小写不敏感**检索，同时检索**【标题+正文】**
- 🎹 **硬核高效快捷键**：全面支持键盘流操作！使用 `Alt + S` 快捷保存当前笔记，`Alt + N` 快速创建全新笔记。
- 🕵️ **隐私安全防护**：登录与注册界面的“密码输入框”全面升级为不可见的暗码状态（`••••••`），切实保障周围环境下的密码隐私。
- ⏱️ **状态实时追踪**：每条笔记都会精准捕捉最新修改时间，并在编辑区底部配备高灵敏度字数统计，字数变动实时更新。
- 🏎️ **极速登录体验**：本地安全记住登录凭证，再次启动自动勾选“同意用户使用协定”，实现秒进系统。

## 📄 使用教程

### 📌 登录与注册
1. 在登录/注册界面时，系统默认已为你自动勾选【同意用户使用协定】，相应的“登录”与“注册”按钮保持激活状态，支持极速登录。
2. 用户名和密码严格区分大小写。注册账号时，请不要使用已被抢注的相同用户名。
3. 密码输入框已进行掩码保护，防止被窥屏。

### 📌 笔记本核心使用
1. **内置教程**：每个新账号创建后，系统都会自动生成一篇《应用介绍与使用教程》并锁死置顶，帮助你快速上手。
2. **新建与删除**：点击顶部【创建】按钮（或快捷键 `Alt + N`）即可生成新笔记并自动跳转；选中非教程笔记后点击【删除】即可移除。
3. **精准检索**：在搜索框中输入任意关键字，点击【查询】后，左侧列表所有命中笔记会变为淡黄色持久高亮。

## 💛 获取应用

### 📦 源码获取
本项目源代码由 8 个核心 `.java` 文件构成，代码结构严谨规范，你可以直接通过克隆或下载本仓库获取：
`git clone https://github.com/nannana11/Notebook.git`

### 🚀 Release 运行版下载
1. 前往本仓库的 **[Releases]** 页面，下载最新的 `Notebook_version1.2_release.zip` 压缩包。
2. 将压缩包完整解压到本地（请确保 `Notebook_version1.2.exe` 与 `jre` 文件夹保持在**同一层级目录下**）。
3. 直接双击 `Notebook_version1.2.exe` 即可运行！推荐右键该文件选择“创建桌面快捷方式”，日常使用更方便。
