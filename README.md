# 笔记本应用 📖

一个非常方便的电脑桌面随手记应用 💡

## 应用介绍 📬

### 适用场景 ✨

* 📖 课堂记录笔记
* 📊 每日记账
* ⏰ 日程安排
* ✍️ 好词好句摘抄

### 功能特点 🛠️

* 🚀 **【随时随地便记】** 设有记住登录密码等功能，界面简单方便，使用起来极为【便捷】！
* 🔐 **【账号登陆】** 密码登陆，隐私性极强！不同账号记录不同内容，笔记方便好整理！
* 🔍 **【标题检索】** 搜索框可以随时根据笔记标题进行检索！立即找到tap想要的笔记！
* ⏰ **【时间记录】** 能看到每条笔记创建或最新修改的时间！
* 🔢 **【实时字数显示】** 每条笔记当前有多少字，自动帮你数清楚！
* 💾 **【本地保存】** 离线模式笔记全部保存在本地，完全不用担心隐私泄露！每次登陆，一键加载以前的笔记！

## 使用教程 📄

### 登陆与注册 📌

* 请在第一个第二个文本框内，依次输入已经创建过的用户名和密码，勾选同意用户协定后，方可登陆
* 若没有账号，可以在勾选同意用户协定后，点击注册按钮，注册新账号
* **特别提醒** ⚠️
    * 登陆以及注册时请勾选【同意用户协定】，方可点击“登陆”和“注册”按钮
    * 用户名和密码区分大小写
    * 注册账号时，请不要使用和已注册过的账号相同的用户名

### 笔记本使用 📌

* 每个账号创建时会自动生成“应用介绍和教程”，此笔记无法编辑与删除
* **新建、保存与删除：** 界面最上方为功能区，每次需要新建一条笔记，请点击“新建”按钮，每次笔记编辑完后请点击“保存”按钮，想要删除某条笔记，请在选中笔记后点击“删除”
* **搜索笔记：** 界面最上方有搜索功能，可在文本框内输入想要检索的内容，点击“搜索”按钮，即可自动选中检索到的笔记，同时展现全部笔记。检索仅检索【标题】，同时仅返回检索到的第一条笔记，如果有多个笔记含有目标内容，仅会返回第一个
* **选择笔记：** 界面左侧有全部笔记的展示区，展示有每则笔记的“标题”与“创建或最新修改时间”，【单击】即可选中该笔记，已选中的笔记背景色会区别于界面中其它的笔记
* **编辑笔记内容：** 界面右侧为笔记内容展示与编辑区，可以随意修改笔记内容
* **底部功能区：** 界面最下方会显示选中的笔记最新的修改时间以及当前的实时正文字数
* **特别提醒** ⚠️
    * 目前笔记不具备【自动保存】功能，请在每次修改后手动保存笔记！若在切换选中笔记之前没有保存当前笔记，则修改内容会丢失
