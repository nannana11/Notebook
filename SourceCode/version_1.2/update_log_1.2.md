# ⏳ Notebook 版本更新日志 (Update Log)

### 🚀 Version 1.2 (2026/05/25) - 最新旗舰版
- **[特性]** 引入自动化存盘机制：优化 `ListSelectionListener` 与 `WindowListener` 状态闭环，切换笔记或关闭窗口时无感自动保存。
- **[特性]** 全局检索系统 2.0：升级为不敏感检索，检索范围扩展至【标题+正文】；
- **[特性]** 全面支持核心操作快捷键：`Alt + S` 快捷保存，`Alt + N` 快捷创建。
- **[安全]** 密码防护升级：重构登录/注册文本框为 `JPasswordField` 隐藏明文，防止窥屏。
- **[优化]** 登录提速：数据层新增协定状态恢复，登录界面一键自动化勾选“同意用户使用协定”。
- **[修复]** 修复了登录初始化阶段由于执行顺序产生空指针异常（NPE）的缺陷。
- **[修复]** 修复了显示或切换笔记时极端情况下边界值（`-1` / `size()`）数组越界的隐藏 Bug。

### 📅 Version 1.0 (2026/05/20) - 基础发布版
- **[核心]** 基于 Java Swing 手写完成基础多用户隔离笔记本架构。
- **[存储]** 实现利用 `ObjectOutputStream` 的本地持久化序列化数据存储方案（`userData.dat`）。
- **[功能]** 支持基础的多账号注册、独立登录、笔记新建、笔记手动保存、笔记删除。
- **[功能]** 提供置顶的内置不可编辑/删除的《应用介绍与使用教程》。
- **[UI]** 搭建完成两栏式主布局，底部集成高灵敏度正文字数实时统计面板。
